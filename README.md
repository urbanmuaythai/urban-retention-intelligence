# Urban Muaythai Retention Intelligence

Public weekly retention dashboard for Urban Muaythai.

The published site intentionally excludes phone numbers, source CSV files, raw attendance exports, and build-time datasets. Member names remain visible as requested.

## Urban Member Care

The `coach-app/` directory adds an authenticated weekly outreach workspace with Supabase-backed staff notes, follow-ups and expiring exemptions. See [setup, weekly import and deployment](coach-app/README.md). Vercel and Netlify configuration is provided at the repository root. The existing static report remains separate from private staff records.
